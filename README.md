Process Guard AI

Process Guard AI is a machine learning-driven quality control system designed to proactively identify manufacturing batches at risk of defects. By leveraging advanced gradient boosting, the model helps organizations optimize production processes and minimize waste through data-driven insights.

Features
- Predictive Quality Control: Automatically flags manufacturing batches at risk of failure or defects before they occur.
- High Accuracy: Achieves ~90% accuracy on unseen test data using optimized classification algorithms.
- Feature Importance Analysis: Conducts in-depth feature analysis to isolate the most critical process parameters driving product quality.

Tech Stack
- Programming Language: Python
- Machine Learning / Data Science: Scikit-learn, XGBoost, Pandas, Matplotlib
